# 七零喵僵尸末日生存mod (QLM Zombie Apocalypse)
**制作团队：七零喵团队 (SevenZeroMeowTeam)**

一个基于 Minecraft Forge 1.20.1 的末日生存 mod，提供动态难度、月相系统、僵尸进化、AI优化、尸潮、Boss战斗、建筑宝箱注入、计分板HUD等丰富内容。

---

## 玩法规则

### 动态难度系统

游戏根据天数自动切换难度阶段，无需手动设置。

| 阶段 | 天数范围（默认） | 难度 | 僵尸进化概率 |
|------|------------------|------|-------------|
| 安全日 | 1 - 25 | PEACEFUL | 0% |
| 简单 | 26 - 50 | EASY | 15% |
| 普通 | 51 - 100 | NORMAL | 30% |
| 困难（锁定）| 101 - 150 | HARD | 45% |
| 极限（锁定）| 151+ | HARD | 60% |

> 天数范围可通过配置文件 `qlmzombie-common.toml` 调整。

### 月相系统

- **血月**：安全日后每 **14 天**一次（第 28、42、56 天…），怪物刷怪量大幅增加，禁止睡觉，触发尸潮
- **幸运之月**：随机 7% 概率触发，在线玩家获得 Luck II buff 直到天亮
- **丰收之月**：随机 7% 概率触发，作物随机刻强度翻倍

### 僵尸进化系统

进化僵尸会获得额外 buff 和生命值，名字显示为红色：

- **初期（简单）**：速度 I
- **中期（普通）**：2 种随机 buff（速度/伤害/抗性等）
- **后期（困难）**：3 种随机 buff + 额外生命
- **极限**：4 种随机 buff（含再生）+ 大量额外生命

### 🤖 AI 玩家系统

AI 玩家是驯服型战斗伙伴，可进食、装备、挖矿、使用所有常见工作站，功能全面。

#### 生成方式

| 方式 | 说明 |
|------|------|
| **主世界随机生成** | 默认启用，每 3 分钟检测一次，15% 概率在玩家周围生成 |
| **指令生成** | `/qlm aiplayer spawn [名字] [皮肤URL]` |

> 随机生成参数可在 `qlmzombie-common.toml` 的 `[ai_player_spawn]` 中调整：
> - `enableAiPlayerSpawn` — 总开关（默认 true）
> - `aiPlayerSpawnChance` — 检测时生成概率（默认 0.15 = 15%）
> - `aiPlayerSpawnInterval` — 检测间隔秒数（默认 180 = 3分钟）
> - `aiPlayerMaxCount` — 世界中最大AI玩家数量（默认 10）
> - `aiPlayerSpawnRadius` — 生成半径范围（默认 64 格）

#### 生成命令

| 命令 | 说明 |
|------|------|
| `/qlm aiplayer spawn` | 生成默认AI玩家（史蒂夫皮肤） |
| `/qlm aiplayer spawn <名字> <皮肤URL>` | 生成指定名字和皮肤的AI玩家 |

> 生成时有 **25% 概率** 手持动态 mod 武器，运行时扫描所有加载的 mod 武器：
> - **TACZ** 枪械（自动附带64发子弹，子弹无限）
> - **拔刀剑** (SlashBlade) 各类型刀剑
> - **斯巴达武器** (Spartan Weaponry) 全部武器
> - 覆盖 libs 文件夹中几乎所有 mod 的武器（按100+关键词匹配）
> - 无 mod 武器时回退到附魔下界合金剑

> 提示：计分板已简化为核心数据行，无标题或装饰线，不遮挡游戏画面。

## 时间系统

mod 采用自定义时间流速，**比原版 MC 更慢**：

| 项目 | 原版 Minecraft | 本 mod |
|------|----------------|--------|
| 每小时 tick 数 | 1,000 | **2,400** |
| 每天 tick 数 | 24,000 | **57,600** |
| 一天现实时长 | 约 20 分钟 | **约 48 分钟** |

- 天数、难度阶段切换、血月间隔、成就里程碑等**均基于 57600 tick/天**计算
- 计分板中的时间显示自动适配此体系（tick 0 对应清晨 06:00）
- `/qlm day <N>` 命令设置天数也基于此 tick 体系

> - `enableHealthBar` — 是否启用经验条样式血条（默认 true）

## 配置说明

游戏首次启动后会生成配置文件：`<Minecraft 实例>/config/qlmzombie-common.toml`

### 主要配置节点

| 节点 | 说明 |
|------|------|
| `[difficulty]` | 各阶段天数范围、难度锁定开关 |
| `[moon]` | 血月间隔天数、幸运月/丰收月概率 |
| `[zombie_evolution]` | 各阶段僵尸进化概率、额外生命值、装甲僵尸概率 |
| `[ai_optimization]` | AI 总开关、僵尸破门/破方块/搭方块、自爆/木桶概率、骷髅必中箭、村庄守卫者等 |
| `[ai_player_spawn]` | AI玩家主世界随机生成开关、生成概率、检测间隔、最大数量、生成半径 |
| `[music]` | 音乐系统总开关、音量、各场景播放间隔 |
| `[building_loot]` | 建筑宝箱注入总开关、注入概率 |
| `[health_ui]` | 经验条样式血条开关、原版心形隐藏开关、位置/尺寸 |
| `[chain_mining]` | 连锁挖矿/砍树开关、单次最大连锁方块数 |

## 命令系统

| 命令 | 权限 | 说明 |
|------|------|------|
| `/qlm info` | 所有人 | 查看当前状态（天数/阶段/难度/月相/配置/mod 状态） |
| `/qlm day` | 所有人 | 查看当前天数 |
| `/qlm day <天数>` | OP | 设置游戏天数，自动切换难度阶段 |
| `/qlm phase` | 所有人 | 查看当前阶段详情 |
| `/qlm phases` | 所有人 | 查看所有 5 个阶段一览 |
| `/qlm difficulty` | 所有人 | 查看当前难度和锁定状态 |
| `/qlm mods` | 所有人 | 查看内部 mod 列表、冲突检测及处理结果 |
| `/qlm download` | OP | 重新释放所有内部 mod（完成后需重启） |
| `/qlm aiplayer spawn [名字] [皮肤URL]` | OP | 生成 AI 玩家 |
| `/qlm aiplayer list` | 所有人 | 列出所有 AI 玩家（含驯服状态） |
| `/qlm aiplayer tp <名字>` | OP | 传送到指定 AI 玩家身边 |
| `/qlm aiplayer tame <玩家>` | OP | 强制驯服最近 AI 玩家 |
| `/qlm aiplayer skin <URL>` | OP | 设置最近 AI 玩家皮肤 |
| `/qlm aiplayer kill` | OP | 移除最近 AI 玩家 |
