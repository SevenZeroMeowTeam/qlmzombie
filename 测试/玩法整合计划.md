# 玩法整合计划（源码原创实现）
# 遵循开源代码准则：仅参考设计模式/游戏玩法，不直接复制开源代码
# 实现后对应 mod JAR 从「src/libs 释放清单」中移除

## ============================================================
## 总原则（build.16.0 确认）
## ============================================================

> **🔴 最高优先级：尽可能保留原 mod 纹理 / 模型 / 语言文件 / 自定义物品**
>
> 由于目前时间紧张且不熟悉资源制作，源码替代**仅做「无资源纯逻辑」mod**：
> - ✅ 可替代：JAR 内不含 `assets/<modid>/textures` / `models` / `recipes` / `lang`
>   —— 即 mod 只修改游戏行为、不新增任何物品/方块/纹理/翻译
> - ❌ 不替代：只要 JAR 里有 `textures`、`models`、`recipes`、`lang` 任一目录
>   —— 继续保留原 JAR 释放，避免纹理丢失、物品注册缺失、lang 报错
>
> 筛选方法：`[System.IO.Compression.ZipFile]::OpenRead(jar).Entries`
>           搜 `assets/<modid>/textures|models|recipes|lang`，命中 → 不替代

## 审计流程（以后新增/复审第二批都照这个跑）
## ============================================================
```powershell
Add-Type -AssemblyName System.IO.Compression.FileSystem
$libs = 'c:\Users\Administrator\Desktop\qlmzombie-main\src\libs'
$jars = Get-ChildItem $libs -Filter *.jar
$skipFirst6 = @('AlwaysEat','SkeletonAIFix','FastWorkbench','FastFurnace','FastSuite','dropthemeat','肉多多','工作台性能优化','熔炉性能优化','配方性能优化','吃不停','骷髅 AI 修复')
$results = foreach ($j in $jars) {
  if (($skipFirst6 | Where-Object { $j.Name -like "*$_*" }).Count) { continue }
  $z = [IO.Compression.ZipFile]::OpenRead($j.FullName)
  $e = $z.Entries.FullName
  $z.Dispose()
  $check = @{
    T=[bool]($e -match 'assets/.+/textures/')
    M=[bool]($e -match 'assets/.+/models/')
    R=[bool]($e -match 'data/.+/recipes/')
    L=[bool]($e -match 'assets/.+/lang/')
    B=[bool]($e -match 'assets/.+/blockstates/')
    S=[bool]($e -match 'assets/.+/sounds/')
    LT=[bool]($e -match 'data/.+/loot_tables/')
  }
  [PSCustomObject]@{
    Jar=$j.Name
    T=$check.T; M=$check.M; R=$check.R; L=$check.L; B=$check.B; S=$check.S; LT=$check.LT
    PureLogic = -not ($check.T -or $check.M -or $check.R -or $check.L -or $check.B -or $check.S -or $check.LT)
  }
}
$results | Where-Object PureLogic | Format-Table Jar  # 二次复核
```
